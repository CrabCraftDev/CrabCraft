# `crab_world`

Crate that aims to support all world-related functionalities:

- Minecraft world format - anvil
- Holding and modifying chunks stored in paletted format
- System for creating, modifying, etc., blocks

## Blocks

The blocks system is designed to support dynamic blocks (not just at compile time), enabling CrabCraft to support modded
clients in the future. The primary representation of a block is through `Block`.

### Features

- **Dynamic Block Support**: Allows for the creation and modification of blocks at runtime.
- **Vanilla Block Generation**: All vanilla blocks are generated by `build.rs` and added to a global registry of blocks.
- **Block Data Access**: Provides data about blocks in the form of a hashmap. The `BlockData` structure allows for typed
  access to these fields.

### Usage

To get data about a block, you can use the provided struct `BlockRegistry`. For typed access, use the `BlockData`
structure.

### Examples

```rust
let block = GrassBlock::default_state_id().unwrap();
let is_snowy = block.property::<Snowy>().unwrap();

assert_eq!(is_snowy, Snowy { snowy: false });
```
